# ScreenSpeaker-plasmoid
Shows animated virtual speakers as a kde plasmoid.

# Where to get

Github release (coming soon)
Plasmoid store: https://www.opendesktop.org/p/2369856/

# How to use
 - For stereo speakers and sub add 3 instances of the plasmoid and use the channel selction config to select chanel.
 - To make the speakers the same size, use the size config.
